# Automated-Information-Services

This project became the core of my services due to the valuable information it provides for clients that saves them time and money.
As a game service, this database targets the boring part of the game that no one wants to complete but is absolutely necessary to progress.
The database contains the entirety of a gamepath that would normally take weeks to complete, but can be done within an hour.
Not only does it contain tailored formulas throughout the sheet to the specific client, but also accurate estimates of required resources and valuable instructions.
The template is resuseable and is one of my most successful project in the business.
